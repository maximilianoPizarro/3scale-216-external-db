# Operación día 2 (BDD in-cluster)

Tras `externalComponents`, el operador 3scale **no** gestiona PostgreSQL ni los dos Redis. Quien opera `3scale-db` asume pod, PVC, imagen, backup y red. Zync DB puede seguir interna.

Versión para el sitio (EN/ES): `website/docs/day-2.md`. Referencia corta de logs/PVC: [04-ops-logs-persistencia-imagenes.md](04-ops-logs-persistencia-imagenes.md).

## Checklist en régimen

- [ ] ConfigMap Redis con `save` y `appendonly yes` (no `save ""`)
- [ ] GitOps `redis-config.path` = `kustomize/bases/redis-config-persist` (o overlay `*-persist`)
- [ ] Digest SHA-256 anclado (PostgreSQL 15, Redis 7)
- [ ] PVC y `resources` copiados de 2.15 (lab es ejemplo: `1Gi` / `2Gi`)
- [ ] `pg_dump` + VolumeSnapshot periódicos
- [ ] Redis `SAVE` / `dump.rdb` / AOF + snapshot periódicos
- [ ] Backup de secrets en `3scale` (`system-database`, `system-redis`, `backend-redis`) y `system-database` en `3scale-db`
- [ ] Ejercicio de restore al menos una vez
- [ ] Logs stdout → ClusterLogForwarder (`app=system-postgresql-external`, `backend-redis-external`, `system-redis-external`)
- [ ] NetworkPolicy: 5432 y 6379 solo desde el namespace 3scale
- [ ] Pull secret `registry.redhat.io` en `3scale-db`
- [ ] Drain de nodo o rollout de imagen = ventana (1 réplica, `Recreate`, RWO)

## Redis persistente

```bash
oc -n 3scale-db get configmap redis-config-external -o yaml | grep -E 'save |appendonly'
```

`extraValueFiles` tiene que ser `/values-216-external.yaml` (`threescale.redis.configMode: persist`). Si el Pattern sigue en `values-cutover.yaml`, un restart pierde datos.

## Digest (CVE RHSCL)

El operador 3scale ya no hace ImageChange. Poner el digest en `threescale.images` de `values-global.yaml`. Procedimiento: [08-pin-image-digests.md](08-pin-image-digests.md).

```bash
oc get deploy -n 3scale-db -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{.spec.template.spec.containers[0].image}{"\n"}{end}'
```

Matriz 2.16: PostgreSQL ≥ 15.0 (system), Redis ≥ 7.2. Consultar [Supported Configurations](https://access.redhat.com/articles/2798521).

## GRANT PostgreSQL 15 (tras restore)

Comando canónico: [01-externalize-postgresql.md](01-externalize-postgresql.md) (sección GRANT). Sitio: `website/docs/externalize-postgresql.md#grant-create-on-schema-public`.

## Rotación de password

Actualizar `system-database` en `3scale-db` y el `URL` / URLs Redis en el namespace `3scale`. Reiniciar PostgreSQL y `system-app`.

## Qué no hacer

- Redis Cluster (no soportado para 3scale).
- Borrar el namespace `3scale-db` (sí borra PVC). Borrar el APIManager no debe borrar esos PVC.
- Mezclar upgrade de OpenShift y de 3scale en la misma ventana.
- Meter `zync-database` en este runbook.
