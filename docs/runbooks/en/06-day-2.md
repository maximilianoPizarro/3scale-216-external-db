# Day 2 operations (in-cluster databases)

After `externalComponents`, the 3scale operator **does not** manage PostgreSQL or the two Redis instances. Whoever operates `3scale-db` owns pod, PVC, image, backup, and network. Zync DB may stay internal.

Site version (EN/ES): `website/docs/day-2.md`. Short logs/PVC reference: [04-ops-logs-persistence-images.md](04-ops-logs-persistence-images.md).

## Steady-state checklist

- [ ] Redis ConfigMap with `save` and `appendonly yes` (not `save ""`)
- [ ] GitOps `redis-config.path` = `kustomize/bases/redis-config-persist` (or `*-persist` overlay)
- [ ] SHA-256 digest pinned (PostgreSQL 15, Redis 7)
- [ ] PVC and `resources` copied from 2.15 (lab is example: `1Gi` / `2Gi`)
- [ ] Periodic `pg_dump` + VolumeSnapshot
- [ ] Periodic Redis `SAVE` / `dump.rdb` / AOF + snapshot
- [ ] Backup secrets in `3scale` (`system-database`, `system-redis`, `backend-redis`) and `system-database` in `3scale-db`
- [ ] Restore exercise at least once
- [ ] Logs stdout → ClusterLogForwarder (`app=system-postgresql-external`, `backend-redis-external`, `system-redis-external`)
- [ ] NetworkPolicy: 5432 and 6379 only from namespace 3scale
- [ ] Pull secret `registry.redhat.io` in `3scale-db`
- [ ] Node drain or image rollout = window (1 replica, `Recreate`, RWO)

## Persistent Redis

```bash
oc -n 3scale-db get configmap redis-config-external -o yaml | grep -E 'save |appendonly'
```

`extraValueFiles` must be `/values-216-external.yaml` (`threescale.redis.configMode: persist`). If the Pattern stays on `values-cutover.yaml`, a restart drops data.

## Digest (RHSCL CVE)

The 3scale operator no longer triggers ImageChange. Set the digest in `threescale.images` in `values-global.yaml`. Procedure: [08-pin-image-digests.md](08-pin-image-digests.md).

```bash
oc get deploy -n 3scale-db -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{.spec.template.spec.containers[0].image}{"\n"}{end}'
```

Matrix 2.16: PostgreSQL ≥ 15.0 (system), Redis ≥ 7.2. See [Supported Configurations](https://access.redhat.com/articles/2798521).

## Password rotation

Update `system-database` in `3scale-db` and `URL` / Redis URLs in namespace `3scale`. Restart PostgreSQL and `system-app`.

## Do not

- Redis Cluster (not supported for 3scale).
- Delete namespace `3scale-db` (deletes PVCs). Deleting the APIManager must not delete those PVCs.
- Mix OpenShift and 3scale upgrade in the same window.
- Include `zync-database` in this runbook.
